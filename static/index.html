LPG 套利监控与跟盘 App

本地计算 + 信号监控：输入行情后实时给出 PG/PP 套利区间、跟盘建议与预警。

纯前端运行 适配 GitHub Pages

监控参数

阈值用于触发“套利机会”信号；自动刷新=0 表示关闭。

行情输入（JSON 数组）

字段：month, PG, FEI, CP, FX, PP
